## 1. 目標

把介面的越南文(`vn`)、泰文(`th`)從「只有骨架(nav/fkeys/common/settings 約 40 鍵)」補到與繁中(`tw`)**同等完整**,語言切換器已可選這兩種語言。

## 2. 現況與做法

- i18n 為自製 React Context,**真來源是 `LanguageContext.jsx` 內嵌 `translations` 物件**(非 `locales/` 死碼),以 `tw` 為 10 大節結構準繩。
- `vn`/`th` 原本只做了 `nav/fkeys/common/settings`,**缺 `dashboard/orders/reports/analysis/modals/ui` 六節**(各約 243 鍵)。
- **順帶發現**:`cn`/`en` 也各缺 1 鍵 `orders.products.maintenance_title`,一併補齊。
- 做法:以 `tw` 六節為結構範本,派兩個平行子代理各自產出越/泰完整同構物件,整合後以「鍵集合對等測試」把關。沿用既有已定術語(如 楞=Sóng/ลอน、班別=Ca/กะ、車速=Tốc độ/ความเร็ว)。

- **沿用既有 `vn`** 代表越南語(需求文件寫 ISO `vi`),避免動到 `LanguageSwitcher` 與所有既有 `setLanguage('vn')` 呼叫。文件註記:未來若標準化為 `vi`,須同步改切換器與所有呼叫。
- 未啟動 `locales/` 拆檔重構(spec S3 Phase 2 選配);未加 localStorage 語言持久化(選配,未做)。
