## 6. AC-8:tunnel/轉址處置說明

### 6.1 現況查證(2026-07-07 00:27 +0800)

| 項目 | 指令 | 結果 |
|---|---|---|
| mms DNS | `dig @1.1.1.1 mms.ericchh.work A` | **NXDOMAIN**(不在 Cloudflare DNS,亦即不在 tunnel) |
| mms HTTP | `curl -sI https://mms.ericchh.work` | 無法連線(DNS 不存在) |
| smartparts DNS | `dig @1.1.1.1 smartparts.ericchh.work A` | NOERROR(104.21.2.19 / 172.67.128.150,仍在 Cloudflare) |
| smartparts HTTP | `curl -sI https://smartparts.ericchh.work`(重試一次) | **HTTP/2 403**(兩次一致;未 301、hostname 未移除) |

### 6.2 判定:前置不成立,依規格 §2.6 中止此工作項並回報

- `mms.ericchh.work` 不在 tunnel 設定(NXDOMAIN)→ 觸發 §2.6 Edge case「中止此工作項並回報」,其他工作項不受影響。
- 主系統 cloudflared 為 **token 模式**,hostname 路由由 Cloudflare Zero Trust 儀表板遠端管理,repo 內僅有 `CLOUDFLARE_TUNNEL_TOKEN`、**無 Cloudflare API 憑證**(已 grep `.env`/compose/scripts 確認)→ RD 無儀表板/API 權限,依 §2.6 交付「手動操作指引 + 驗證指令」,**不虛報已完成**。

### 6.3 手動操作指引 — **待 Eric 手動執行**(採首選方案:移除 smartparts hostname + 301 Redirect Rule)

**第一步(前置,必須最先做):建立 `mms.ericchh.work` public hostname**

1. 登入 Cloudflare Zero Trust 儀表板(one.dash.cloudflare.com)→ Networks → Tunnels。
2. 選擇 MM 服務所在的 tunnel(若 MM 有獨立 tunnel 選該條;若共用主系統 tunnel 則選 `printingiot-cloudflared-1` 對應那條)→ 分頁「Public Hostname」→「Add a public hostname」。
3. 填入:Subdomain `mms`、Domain `ericchh.work`;Service 依 MM 前端實際入口填(Type `HTTP`,URL 例:`mms-frontend:80`,以 MM compose 內服務名與 port 為準)。
4. 儲存。Cloudflare 會自動建立 `mms.ericchh.work` 的 proxied DNS 紀錄。

**第二步:移除 `smartparts.ericchh.work` public hostname**

5. 在同一 Tunnels 頁面找到 `smartparts.ericchh.work` 的 public hostname 項目 → 刪除。
6. 到 Cloudflare 儀表板(dash.cloudflare.com)→ 網域 `ericchh.work` → DNS,確認 `smartparts` 的 CNAME 紀錄仍存在且為 Proxied(橘雲)— 301 規則需要 DNS 紀錄留著才會生效;若刪 hostname 時連 DNS 一併刪除,補建一筆 `smartparts` CNAME 指向 `<tunnel-id>.cfargotunnel.com`(Proxied)。

**第三步:建立 301 Redirect Rule**

7. 網域 `ericchh.work` → Rules → Redirect Rules →「Create rule」。
8. 規則內容:
   - When incoming requests match:Custom filter — Hostname equals `smartparts.ericchh.work`
   - Then:Dynamic redirect,Expression `concat("https://mms.ericchh.work", http.request.uri.path)`(或 Static `https://mms.ericchh.work`),Status code **301**,勾選 Preserve query string。
9. 儲存並部署。

**驗證指令(執行完 1–9 後)**

```bash
curl -sI https://mms.ericchh.work           # 預期 200(或登入頁 30x)
curl -sI https://smartparts.ericchh.work    # 預期 301 且 Location: https://mms.ericchh.work...
dig @1.1.1.1 mms.ericchh.work A +short      # 預期回 Cloudflare IP(不再 NXDOMAIN)
```

若 DNS/憑證快取造成抖動,間隔 1–2 分鐘重試一次;仍異常記錄回應碼與時間交人工判讀。
