## 4. 延後項目

### #5 [high] di3-di10 機台部位狀態燈永遠 OFF

**查證結論(需後端 + 硬體決策,非安全前端修正)**:
- 後端 `PrintingIoT.Core/Models/MonitorData.cs` 僅 5 欄:`DeviceId / Speed / di1 / Status / Timestamp`,`GET /api/monitor/realtime` 從 Redis `factory/monitor` 反序列化後**根本不含 di3-di10**。
- `StatusPanel.jsx` 對有配置 `errorSignal` / `runSignal`(如 di3~di10)的機台部位,因 `currentData` 無該欄位,訊號判斷恆 false → 顯示灰色 OFF。無配置訊號的部位則正常 fallback 至全域 motor 狀態。
- 修復需三步:(a) WISE 模組 DI 點位 → 機台部位對映決策(Eric / 硬體端);(b) 後端 `MonitorData` 擴充 di3-di10 + Worker 寫入 Redis;(c) 前端 polling 映射。**待 Eric 提供 DI 對映後再實作。**
