## 4. 關鍵處理

- **動態值**:`t()` 無插值 → 含變數的 alert 以佔位字串 `{speed}`/`{qty}` + JS `.replace()`,或 pre/mid/post 三鍵模板拼接(語序依語系調整)。
- **不良類別/停機原因**:改以 `reasonKey` 存 i18n 鍵、渲染時 `t()`,語言切換即時反映。
- **重複英文副行**:Schedule/MaintenancePage 的英文 diagram 提示行刪除(主行 i18n 已表達)。
- **命名**:新鍵放 `modalExt`(印後/表單/訂單警示/help)與 `docs` 兩個新命名空間,零風險不動既有 `settings.*`/`modals.*`。
