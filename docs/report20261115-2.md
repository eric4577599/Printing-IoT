## 過程中發現的問題
1. **部署後整頁空白(已修)**:`index.html` 沒有 `Cache-Control`,瀏覽器自行估算快取;部署後舊 `index.html` 指向已被換掉的 `index-*.js`,而 nginx `try_files` 對不存在的檔案回退成 `index.html`(200)→ 被當 JS 執行失敗。修法:`/` 加 `no-cache`;`/assets/` 設長期快取並 `try_files $uri =404`。已驗證:`Cache-Control: no-cache`,不存在的資產回 404。
2. **設定頁左側選單沒有樣式(B21,未修)**:`SettingsPage.module.css` 完全沒有 `sidebar` / `menuItem` / `sidebarHeader` / `active`,自最早 commit 即如此。
3. **作業員可開啟通訊設定、計算公式分頁(B22,未修)**:儲存由後端擋,但前端先樂觀更新本機狀態。
4. **ERP 區塊顯示異常(B23,未修)**:連線方式未選,輸入/輸出路徑顯示 `192.168.1.100` / `3000`。
