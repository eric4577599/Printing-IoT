## 為什麼要做這一輪

第一輪稽核沒有規格可對照,只能拿一般工程實務判斷程式碼。有規格之後,結論改變三件事:

1. 多條原本標成「缺功能」的發現,實際是**設計了但沒做**,份量比原評級更重。
2. 有些元件從未進入稽核範圍(SQL 與檔案訊息來源、維修故障教學、量測記錄),因為程式碼裡看不出有人打算做。
3. 冒出一個原本抓不到的問題類型,見下節。

## 新增的問題類型:介面做好了,資料到後端就被丟棄

27 個設計元件中有 6 格屬於這一類。從程式碼往外看幾乎抓不到,因為前端元件都在、表單畫得完整,驗收時容易誤判成已實作。

| 元件 | 現況 |
|---|---|
| PLC 直連 | 設定頁有 Modbus 下拉選項與 IP、Port 欄位;後端零 Modbus 程式,選了 Modbus 按「測試連線」跑的仍是 MQTT 用戶端並回報成功 |
| Parameter 訊號對映 | 設定頁已有 `plc_motor_signal`(預設 DI-0)與 `plc_count_signal`(預設 DI-1),存進 Redis 後無任何程式讀取;Worker 硬寫死只認 `di1` |
| 停機原因清單 | 設定頁編輯器存 localStorage 的 `stopReasonsList`;現場彈窗用元件內寫死的六筆常數,從不讀那份清單 |
| 不良原因清單 | 同上,設定頁存 `defectReasonsList`,完工彈窗四個類別是寫死常數 |
| 計量保養觸發設定 | 前端有觸發類型選擇器與張數、PLC、混合三組設定元件與儀表圖;存檔時全部被丟棄,資料庫無欄位可接 |
| 故障回報照片 | 上傳是假的,只產生瀏覽器預覽網址;送出時 payload 根本沒帶照片。維修單號、更換零件序號、剩餘壽命比例同樣被丟棄 |

## 四條軸線的落差摘要

**訊息來源**。四種來源只有 WISE 的計數真的在跑。WISE 的另一種訊號 Motor On 不存在:payload 沒有任何欄位被當成運轉訊號,機台狀態硬寫死字串 `"1"`,前端顯示的「Connected (Motor On)」是本地 UI 狀態。PLC、SQL、檔案三種皆未實作。MM 對訊號來源零管道,無 MQTT 用戶端、無 Redis、無讀主系統 API。

**Stop 與 NG 來源**。兩條訊號都不存在。停機由車速歸零推算,且判定條件要求剩餘量大於 50 且已有產量,接近完工的停機不會被記錄。良品與不良品全靠操作員在完工彈窗手動鍵入。後端無任何停機原因或良率欄位,`ProductionLog` 只有五個欄位。這直接解釋了 OEE 缺 Quality 因子:根因不是公式寫錯,是兩條訊號從來沒有來源。

**共用登入**。實際是三套互不相通的體系:主系統後端 JWT 登入 API 從未被前端呼叫、前端硬編碼假登入(且分兩組不同來源)、MM 自有一套。MM 的 `ErpAuthProvider` 語意是把既有 token 送去上位系統驗身分,不是把帳密送去比對,且部署固定在 local 模式、驗證網址為空,從未觸發。主系統 BCrypt 簽 JWT 效期 2 小時,MM PBKDF2 配資料庫 opaque token 效期 12 小時,技術上無法互通。

**MM 保養功能樹**。週期只支援日、週、月與臨時,季與年不存在。計量保養僅前端外殼。維修故障教學不存在。零件圖庫不存在,且零件本身分裂成備品庫存與採購主檔兩個互不引用的實體,文件無法掛到零件。量測記錄不存在,檢查表只能勾選是否加文字備註。三條交互參照虛線只有「零件 ↔ 維修」連到一半(指向備品而非圖庫零件)。

最關鍵的地基問題:**保養排程與維修紀錄都沒有設備關聯欄位**,整個 MM 只有設備文件有。保養與維修目前無法歸屬到任何一台特定機台,所有計量觸發、設備履歷、跨系統對映都建立在這個缺口之上。

## 修正前一份報告的一處判斷

`docs/report20260903-1.md` 建議「主系統把機台運轉量同步給 MM」。依設計意圖圖,這個方向是錯的:MM 應與主系統**並列掛在同一個訊息來源上**,共用 Parameter 參數契約,而非等主系統轉手。兩種形狀的相依方向不同 —— 前者讓 MM 永遠依賴主系統存活,後者讓 MM 能獨立部署給只買保養模組的客戶。頁面第 04 節已加註修正。

## 建議的優先順序調整

1. **先補資料落地欄位**,再補訊號來源。停機原因、良率、設備關聯這三組欄位不存在,上游訊號補了也留不下來。
2. **Parameter 是最接近完成的一格**,設定介面已在,只差後端消費與四種來源共用。這一格打通,PLC 與檔案來源才有意義。
3. **設備關聯欄位是 MM 的地基**,優先於計量保養與零件圖庫。
4. **六格「介面做好未接後端」要明確決策**:接起來,或從介面移除。留著會持續造成驗收誤判。
