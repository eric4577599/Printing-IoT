## F4 / F10 車速防呆實機驗證
以 `mosquitto_pub` 注入模擬訊號(topic `factory/machine/update`,設備 `GUARD-TEST`),作業員 OP1 在看板按鍵:

| 情境 | 按鍵 | 實際結果 |
|---|---|---|
| 車速 50、計數 1500 | **F4** | 提示「車速不為 0,無法完工!請先停止機台。」,**未開啟完工視窗** |
| 車速 50 | **F10** | 提示「車速不為 0,無法退回!請先停止機台。」,訂單仍在執行中、數量不變 |
| 車速 0、計數 1500 | **F4** | **放行**:開啟「完工確認」視窗,同時自動跳出「停車原因」選單(車速 0 且剩餘 > 50) |

- **沒有送出任何完工**:完工視窗開啟後直接重新載入頁面丟棄;資料庫 `ProductionCompletions` 仍為 294 筆。測試用的 Redis 快照已清除。

## E3(權杖自動換發)
**無法等 2 小時,改驗證機制本身**:保留刷新憑證,把存取權杖換成無效值後重新載入 → 系統**自動換發出新權杖**(與原本不同)、使用者**仍保持登入**、以新權杖呼叫 API 回 200。
**這不等於 2 小時實際計時**;自然過期的情境(含刷新憑證 12 小時到期)未驗。
