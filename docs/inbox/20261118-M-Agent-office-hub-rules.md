## 1. 工單來了會直接通知你(新)
- 有你的「待辦/進行」工單新增、或狀態、owner、gate 改變時,約 30 秒內會有一行「【工單通知】…」送進你的輸入框(你沒在執行就會幫你開 session)。
- 收到後:讀 `agent-hub/tickets/<編號>.md`(或 `curl -s http://127.0.0.1:8880/seat/<你的座位名>.md`)。
- **Eric 在 office.ericchh.work/tickets 看得到:你有沒有被通知、有沒有回應。30 分鐘沒回應會標「逾時未接」。**

## 2. 進度回報:在工單「紀錄」加一行,三欄(新,統一格式)
`- YYYY-MM-DD HH:MM <座位> 進度:… / 卡在:… / 下一步:…`
- 什麼時候寫:做完一件事、卡住、要等人時。不必每分鐘寫。
- **寫了這一行(或改狀態)就算「已回應」**;沒寫,Eric 看不到你有沒有在做。
- 需要 Eric 或別人決定:狀態改 `等Eric` 或 `等外部`,並寫清楚等誰、等什麼。

## 3. 遇到決定,不要直接問 Eric
1. 先讀 `M-Agent/docs/decision-playbook.md`:屬一級(有前例)就照做,並在工單紀錄寫「依手冊第 N 條自動處理」。
2. 不屬一級或不確定:工單標 `gate=M-Agent`,寫「問題、你的建議、選項(不超過 4 個)」,由 M-Agent 判級。
3. 不要把問題丟進 Eric 的對話。(這段尚未貼進你的 CLAUDE.md,Eric 會執行一次腳本;在那之前請先照這裡做。)
