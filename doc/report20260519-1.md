## 修正內容

### Bug:OpenApiContractTests 連 PostgreSQL 失敗

**現象**:
```
PrintingIoT.Tests.Integration.OpenApiContractTests.SwaggerEndpoint_ReturnsValidJsonSchema
System.InvalidOperationException : The ConnectionString property has not been initialized.
```

**根因**:
- `Program.cs` 用 `IsEnvironment("Testing")` 判斷是否跳過 DbContext 註冊與 `MigrateWithRetryAsync`
- 但 Swagger 只在 `IsDevelopment()` 開啟
- 測試為了拿 swagger.json,把環境設成 `"Development"`,反而觸發 DB Migration
- 測試環境沒有 PostgreSQL → 連線字串為空 → 炸

**修法**:三處
1. `backend/PrintingIoT.API/Program.cs:91` —— Swagger 開放範圍從 Development 擴大到 Development 或 Testing
2. `backend/PrintingIoT.API/Program.cs:119` —— 移除重複的 `app.Run();`(死碼)
3. `backend/PrintingIoT.Tests/Integration/OpenApiContractTests.cs:26` —— 測試環境改用 `"Testing"`,Migration 自然跳過

修完後 18/18 全綠。

### 額外:補 frontend test script
