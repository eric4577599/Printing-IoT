4.2 操作步驟

調整排程順序

  1. 在左側選取要移動的工單
  2. 點擊「上移」或「下移」按鈕
  3. 點擊「順序重置」可重新編號(10, 20, 30…)
⚠ 注意正在生產中的工單(第一筆)無法移動。

新增/刪除排程

  1. 在右側產品庫選取產品,點「新增排程」開啟視窗(見 S9)
  2. 刪除排程:左側選取工單後刪除;正在生產的工單需車速為 0 且未生產量為 0

18. 分辨指南:備品庫存 vs 零件主檔

兩個頁籤都跟「零件」有關,但管的事完全不同 — 選錯頁籤是最常見的操作問題

🔩 備品庫存

回答:「保養用什麼?還剩多少?」

  • 保養維修的耗用庫存
  • 維修歸檔自動扣庫存
  • 低於安全庫存亮紅色警示
  • 數字隨保養/維修一直變動

📦 零件主檔 + 🏢 供應商

回答:「跟誰買?規格價格為何?」

  • 採購用的規格主檔
  • 零件 × 供應商 × 報價的關聯
  • 內部料號對應各家原廠料號
  • 資料隨採購決策才更新
我想要…去哪個頁籤
看皮帶還剩幾條🔩 備品庫存
盤點後修正庫存數字🔩 備品庫存 → 編輯
查這顆軸承跟誰買、多少錢📦 零件主檔 → 檢視
新零件建規格資料📦 零件主檔 → + 新增零件
看某家供應商賣哪些東西🏢 供應商
維修時登記用掉的零件📋 維修清單的回報視窗內填寫(自動扣 🔩 庫存)

19. 作業流程圖

跨畫面的完整走法。◆ 黃底 = 判斷分支;虛線框 = 系統自動處理;編號對應第 2 章畫面清單

19.1 主系統:生產作業流程(S1 → S3 → S5)

上工:班別選擇(S1)↓ 即時監控頁確認排程佇列必要時 F1 / F2 調整順序↓ ◆ 車速 = 0?
否先停機送單前必須停機↩ 回到判斷
是按 F3 送單
↓ 生產中數量自動累計;F5 / F6 手動修正↓ ◆ 中途停機?
有選擇停車原因(S6)排除狀況後繼續↩ 回到生產中
無生產至達標
↓ 停機後按 F4 完工↓ 完工確認(S5)良品 / 不良數量、欠量原因、製程類別↓ ◆ 自動下一筆 ON?(F8 切換)
是自動帶入下一筆工單↩ 回到「車速 = 0?」
否本筆結束,人工選下一單

19.2 MM:突發故障維修(M4 → M5 → M10)

發現設備故障↓ 📋 維修清單 →「⚠️ 故障回報」(M5)選故障零件↓ ◆ 廠內修或委外修?
內修廠內人員處理
外修填寫外部維修單號
↓ ◆ 有更換零件?
有填更換狀況新品歸零 / 整修品填 S/N 與壽命比例自動扣 🔩 備品庫存
無僅調整 / 修復
↓ 上傳現場照片(可多張)↓ ◆ 處理完成?
完成勾選功能驗收 + 填驗收人確認並歸檔轉入 📜 歷史紀錄(M10)
觀察中選「持續觀察中」暫不結案,後續再回報

19.3 MM:定期保養(M8 → M4 → M6)

排程觸發到期週期 / 張數 / PLC / 混合(M8)↓ 📋 維修清單出現待辦任務(M4)狀態:即將到期 / 逾期↓ 點「執行」開啟執行回報(M6)↓ 逐項勾選保養重點來自綁定的保養計畫範本(M9)↓ ◆ 必檢項全數勾選?
否顯示黃色提醒可補勾或加註後仍可送出
是直接確認
↓ 確認完成↓ 自動扣排程綁定的備品(🔩)↓ 轉入 📜 歷史紀錄 · 週期重新起算

19.4 MM:備品補貨(M7 → M13 → M14)

🔩 備品庫存出現紅色警示(M7)↓ ◆ 確實低於安全庫存?先查 📜 歷史紀錄近期耗用,排除誤扣
否盤點修正庫存數字即可
是📦 零件主檔查對應零件(M13)
↓ 🏢 查供應商報價(M14)優先供應商先問↓ 下單採購走公司採購流程(系統外)↓ 到貨入庫:🔩 備品庫存「編輯」補上數量↓ 紅色警示解除
ℹ 目前補貨判斷是人工的 「低庫存自動產生採購建議」在未來版本規劃中,目前請依 🔩 頁籤的紅色警示人工發動採購。

19.5 MM:新零件建檔(M13)

新零件進場 / 新採購需求↓ 📦 零件主檔以料號 / 名稱搜尋(M13)↓ ◆ 已建過此零件?
是直接使用必要時在編輯視窗補供應商報價
否「+ 新增零件」內部料號、名稱、規格、分類、單位
↓ 加入供應商報價可多家;主要往來勾「優先供應商」↓ ◆ 屬保養耗材?
是到 🔩 備品庫存(M7)建一筆設定初始庫存與安全庫存
否完成建檔
